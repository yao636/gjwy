Font Awesome 字体图标

用字体文件绘制图标：一个类名就能调用，颜色、大小、旋转全部交给 CSS。 本页所有资源已下载到本地 cdn 目录，断网也能正常显示。

字体渲染 CSS 换色 本地离线可用
01

什么是字体图标

Font Awesome 把图标做成字体文件，每个图标对应一个 Unicode 码位。 页面里写的 <i class="fa-solid fa-house"> 本质上是给文字指定了特殊字体和字符，所以图标能像文字一样被 CSS 控制。

矢量无损

字体轮廓随字号缩放，放大到任意尺寸都不会出现锯齿或模糊。

调用简单

两个类名即可：风格类（solid / regular / brands）+ 图标名类。

完全可控

直接使用 font-size、color、text-shadow 和动画，不需要额外图片。

02

04

代码写法

引入一次样式文件，之后每个图标只需要一行 HTML。

<!-- 1. 引入本地 Font Awesome 样式 -->
<link rel="stylesheet" href="cdn/fontawesome/css/all.min.css">

<!-- 2. 两个类名：风格 + 图标名 -->
<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-heart"></i>
<i class="fa-brands fa-github"></i>

/* 3. 图标本质是文字，直接用 CSS 控制 */
.chen_icon {
  font-size: 32px;
  color: #4f46e5;
}

图标默认继承文字颜色和字号。给父元素设置 color 和 font-size，内部的图标会自动跟随； 装饰性图标建议加上 aria-hidden="true"，避免被读屏软件重复朗读。
