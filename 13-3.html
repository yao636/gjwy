固定底部导航
字体图标版

使用 font 目录下的 iconfont 字体图标，做一个铺满全屏宽度、 4 项等分、始终固定在底部的移动端导航。图标右上角同时演示数字徽章与红点。

固定底部 四等分自适应 安全区适配

点击底部导航即可切换

固定定位

导航使用 position: fixed 固定在视口底部， 页面滚动时始终可见。

四等分自适应

左右各贴边 0，宽度 100%；内部用 4 列 Grid 等分，手机、平板自动适配。

留出安全区

底部加入 env(safe-area-inset-bottom)， 避免被 iPhone 底部横条遮挡。

数字徽章与红点

两种提醒都定位在图标右上角：数字徽章显示具体数量，红点只表示“有新内容”。 首页和“我的”使用红点，消息和订单使用数字徽章。

红点提醒 右上角小圆点

页面底部已预留 padding-bottom， 所以页脚内容不会被固定导航遮住；导航背景铺满屏幕宽度。

关键 CSS

固定、全宽、四等分、安全区，四行核心规则就能搭出底部导航。

/* 导航条铺满全屏宽度并固定在底部 */
.chen_bottom_nav {
  position: fixed;
  left: 0;
  right: 0;
  bottom: 0;
  width: 100%;
  padding-bottom: env(safe-area-inset-bottom);
}

/* 四个导航项等分剩余空间 */
.chen_nav_inner {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
}

/* 数字徽章 / 红点固定在图标右上角 */
.chen_nav_badge,
.chen_nav_dot {
  position: absolute;
  top: -8px;
  right: -12px;
}
