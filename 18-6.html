Mermaid 图表：智能客服系统流程图与 ER 图

基于 mermaid@11 渲染 flowchart 业务流程图与 erDiagram 数据模型图，mermaid.min.js 已下载到本地 cdn/mermaid/ 目录，无需访问在线 CDN

图一：智能客服业务流程图 flowchart TD

用户提问 → 接入与预处理 → 意图识别 → 知识库检索（RAG）→ 命中则生成回答，未命中或用户不满意则转人工；全过程记录满意度并回流更新知识库。

flowchart TD
    A([用户发起咨询]) --> B[接入层
网页 / APP / 小程序]
    B --> C{预处理与鉴权
是否有效会话?}
    C -- 无效 --> C1[拒绝并提示登录]
    C -- 有效 --> D[意图识别
NLU 分类 + 实体抽取]
    D --> E{意图类型?}
    E -- 常见问题 --> F[知识库检索 RAG
向量匹配 Top-K]
    E -- 业务办理 --> G[调用业务 API
订单 / 退款 / 查询]
    E -- 闲聊寒暄 --> H[闲聊回复模板]
    F --> I{置信度达标?}
    I -- 是 --> J[生成回答
大模型润色 + 引用来源]
    I -- 否 --> K[兜底话术
推荐猜你想问]
    G --> J
    H --> J
    K --> L{用户是否满意?}
    J --> M[满意度评价
点赞 / 点踩]
    M -- 不满意 --> L
    L -- 否 / 两次未解决 --> N[转人工客服
创建工单]
    L -- 是 --> O[结束会话
记录日志与评价]
    N --> P[人工处理并回复]
    P --> O
    O --> Q[(会话日志 / 知识沉淀
回流优化知识库)]
    Q -.数据回流.-> F

图二：智能客服数据模型 erDiagram

核心实体：用户、会话、消息、知识条目、工单、客服坐席。一次会话包含多条消息；命中知识条目生成回答；未解决升级为工单并分配给坐席。

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--|{ MESSAGE : "包含"
    SESSION ||--o{ TICKET : "可升级为"
    MESSAGE }o--o{ KB_ENTRY : "引用命中"
    TICKET }o--|| AGENT : "分配给"
    AGENT ||--o{ TICKET : "处理"
    KB_ENTRY ||--o{ KB_FEEDBACK : "收到反馈"
    MESSAGE ||--o| KB_FEEDBACK : "产生"

    USER {
        bigint user_id PK "用户ID"
        string nickname "昵称"
        string channel "来源渠道"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        string status "进行中/已结束"
        float satisfaction "满意度评分"
        datetime started_at "开始时间"
    }
    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint session_id FK "所属会话"
        string role "user/bot/agent"
        text content "消息内容"
        float confidence "回答置信度"
        datetime sent_at "发送时间"
    }
    KB_ENTRY {
        bigint kb_id PK "知识条目ID"
        string title "标题"
        text content "正文"
        vector embedding "语义向量"
        int hit_count "命中次数"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "来源会话"
        bigint agent_id FK "处理坐席"
        string priority "优先级"
        string state "待处理/处理中/已关闭"
    }
    AGENT {
        bigint agent_id PK "坐席ID"
        string name "姓名"
        string group "技能组"
        bool online "是否在线"
    }
    KB_FEEDBACK {
        bigint feedback_id PK "反馈ID"
        bigint msg_id FK "来源消息"
        bigint kb_id FK "关联条目"
        string label "有用/无用"
    }
