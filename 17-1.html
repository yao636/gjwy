什么是 JSON

JSON（JavaScript Object Notation）：一种轻量级的数据交换格式，本质是字符串，与语言无关，常用于前后端数据传输与配置文件。

本质是字符串

JSON 不是对象，而是一段文本；typeof 的结果是 "string"。

键必须双引号

属性名必须用双引号包裹，{name:"陈"} 是非法的。

不能写注释

JSON 中不允许 // 或 /* */ 注释，也不能有多余的尾逗号。

只有 6 种值

对象、数组、字符串、数字、布尔、null；不支持函数、undefined、日期对象。
