12-1 CSS 变量（CSS Custom Properties）

展示 :root 全局变量、局部作用域变量、var() 函数及回退值（fallback）的使用

1. 全局变量（:root）

在 :root 中定义以 --chen_ 开头的自定义属性，整个页面都可以通过 var() 使用。

var(--chen_primary_color)
--chen_bg_color: #f5f7fa;
--chen_text_color: #2f3a4b;
--chen_primary_color: #4d7cfe;
--chen_card_bg: #ffffff;
--chen_radius: 12px;
--chen_padding: 24px;

2. 局部作用域变量（.chen_dark_theme）

CSS 变量具有层叠（Cascading）特性，在某个选择器内重新定义同名变量，只影响该作用域内的元素。

深色主题作用域内的 var()
--chen_bg_color: #0f172a;
--chen_text_color: #e2e8f0;
--chen_card_bg: #16213f;
--chen_border_color: rgba(255,255,255,0.08);

3. 作用域覆盖（绿色强调）

为不同的卡片设置不同的变量值，实现主题化（Theming），而不需要修改组件样式。

var(--chen_primary_color) = #22c55e
--chen_primary_color: #22c55e;
--chen_secondary_color: #4ade80;
--chen_card_bg: #f0fff6;
--chen_border_color: #bbf7d0;

4. var() 函数与回退值（Fallback）

使用 var(--chen_xxx, #999) 可以在变量未定义时提供默认回退值，提升健壮性。

未定义变量 + 回退值（#9ca3af）
background: var(--chen_unknown_color, #9ca3af);
color: var(--chen_text_color, #111111);
border-radius: var(--chen_radius, 8px);

5. CSS 变量的计算与过渡

CSS 变量可以配合 color-mix()、calc()、过渡（transition）等属性使用，实现动态主题切换效果。

主题切换时平滑过渡背景/文字颜色
transition: background-color 0.3s ease, color 0.3s ease;
color: color-mix(in srgb, var(--chen_text_color) 75%, transparent);
border-radius: calc(var(--chen_radius) - 4px);

6. 总结

CSS 自定义变量（Custom Properties）让样式更具可维护性、可复用性和可扩展性。结合局部作用域可以轻松实现多主题、组件样式变体等设计需求。
