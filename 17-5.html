JavaScript 两种定时器演示

setTimeout（到点执行一次）与 setInterval（每隔一段时间反复执行），以及对应的清除方法

一次性定时器 setTimeout

3 秒后触发一次提醒；触发前可随时用 clearTimeout 取消。定时器返回一个编号（id），取消时就是用它。

空闲中，还没有定时器

周期性定时器 setInterval

每 100 毫秒刷新一次秒表，直到调用 clearInterval 才会停止。

两种定时器对比

对比项setTimeoutsetInterval
执行次数延迟到期后执行 1 次每隔指定毫秒执行，直到清除
清除方法clearTimeout(id)clearInterval(id)
返回值都是数字编号 id（在浏览器里两套编号互相混用也能清除）
典型用途延迟提示、防抖、动画补帧秒表、轮播图、倒计时、轮询
常见坑到点后若主线程忙碌，会顺延执行，不保证精确回调耗时会堆积；建议用“链式 setTimeout”代替

id 一定要保存

想取消定时器，必须在启动时把返回值存下来：chenId = setTimeout(...)，否则无法停止。

切换页面前记得清除

单页应用销毁页面组件时，若不清除 setInterval，回调会一直空跑造成内存泄漏。

周期任务推荐写法

回调结束后再安排下一次：function loop(){ 工作(); setTimeout(loop, 1000); } 可避免任务堆积。

最小间隔 4ms

规范规定嵌套 5 层以上的 setTimeout 最小间隔被强制为 4ms，写 0 也做不到真正“立即”。
