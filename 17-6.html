两种写法核心代码

写法一：Promise 链

chenSleep(6000) .then(() => { /* 买原料完成 */ }) .then(() => chenSleep(2000)) /* 取原料 */ .then(() => Promise.all([ chenSleep(4000), /* 和面 */ chenSleep(3000) /* 和馅 */ ])) .then(() => chenSleep(5000)) /* 包饺子 */ .then(() => chenSleep(3000)); /* 吃饺子 */

写法二：async/await

async function makeDumplings() { await chenSleep(6000); /* 买原料 */ await chenSleep(2000); /* 取原料 */ await Promise.all([ chenSleep(4000), /* 和面 */ chenSleep(3000) /* 和馅 */ ]); await chenSleep(5000); /* 包饺子 */ await chenSleep(3000); /* 吃饺子 */ }
