固定底部导航
SVG 图标版

同样使用 font 目录下的 iconfont， 但这次改用 iconfont.js 的 SVG symbol 精灵图。 导航依旧全宽固定，4 项等分，并带数字徽章与红点。

点击底部导航即可切换

固定定位

position: fixed 让导航脱离文档流， 始终贴在视口底部。

四等分自适应

导航条宽度 100%，内部 4 列 Grid 平分空间，屏幕变宽变窄都不错位。

SVG 可着色

symbol 中的路径使用 currentColor， 选中状态只需要修改文字颜色。

数字徽章与红点

徽章仍然定位在图标右上角。消息显示 12，订单显示 3； 首页和“我的”用纯红点表示有新内容。

12 数字徽章 12 条未读消息
红点提醒 右上角小圆点

图标是真正的 <svg> 元素， 可以用 CSS 设置 fill、 width 和 height， 放大也不会模糊。

SVG 用法

先引入本地 iconfont.js，它会注入 symbol 精灵图；页面里用 use 引用图标 id。 

<!-- 1. 引入 iconfont.js，注入 SVG symbol -->
<script src="font/font_5244855_fm8s0yq40te/iconfont.js"></script>

<!-- 2. 用 svg + use 引用图标 -->
<svg class="chen_nav_svg" viewBox="0 0 1024 1024">
  <use href="#icon-xiaoxi"></use>
</svg>

/* 3. 图标跟随父元素颜色 */
.chen_nav_svg {
  width: 24px;
  height: 24px;
  fill: currentColor;
}
