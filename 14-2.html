02

代码实现

用 var / let / const 声明六个变量，分别对应六种类型

// 1. String 字符串
let chen_name = "陈弘毅";

// 2. Number 数值（整数和浮点数）
const chen_age = 18;
var  chen_pi   = 3.14;

// 3. Boolean 布尔（真或假）
let chen_isStudent = true;

// 4. Undefined 未定义（声明但未赋值）
let chen_hobby;

// 5. Null 空值（主动赋空）
let chen_score = null;

// 6. Object 对象（数组、函数等引用类型也归于此）
let chen_info = { name: "陈弘毅", age: 18 };
